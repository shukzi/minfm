# minfm changelog

## v0.1.0

Initial release.

- Terminal file browsing, search, file operations, and trash management.
- Archive and compression support, including ZIP extraction with path checks
  and removal of SUID, SGID, and sticky permission bits.
- Optional disk, partition, LUKS, and network-share tools.
- A static Linux binary, installer, bundled icons, and update support.
- A concise README, detailed user guide, and public bug and suggestion forms.
